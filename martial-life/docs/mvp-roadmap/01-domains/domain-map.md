# domain-map.md

## 도메인 목록

### 1. 캐릭터/성장 도메인 (Character Growth)

책임 범위: 주인공의 경지, 무공 보유 현황, 능력치 등 "주인공 자신의 상태"를 관리한다.

포함: 경지 단계(평민→삼류 등), 보유 무공 목록, 경지 상승 조건 충족 여부 판정
포함하지 않음: 무공을 배우게 되는 계기(그건 서사 도메인), 다른 인물과의 관계 수치(관계 도메인)

관련 기존 산출물: 규칙_호감도_경지.md 중 "경지 상승 조건" 부분

---

### 2. 관계 도메인 (Relationship)

책임 범위: 주인공과 각 NPC 간의 관계 수치와 상태(호감/중립/불신/적대)를 관리한다.

포함: 호감도 수치, 수치 구간별 상태 판정, 인물별 관계 이력
포함하지 않음: 관계 변화를 일으키는 대화·사건 자체(서사 도메인), 관계 결과로 발생하는 보상(성장 도메인)

관련 기존 산출물: 규칙_호감도_경지.md 중 "호감도" 부분, 인물_설매.md의 태도 매트릭스

---

### 3. 서사/이벤트 도메인 (Narrative)

책임 범위: 상황 제시, 선택지 제공, 선택에 따른 분기와 결과(엔딩 포함)를 관리한다.

포함: 대화 스크립트, 선택지 구조, 분기 로직, 엔딩(성공/실패/사망 엔딩 전체)
포함하지 않음: 선택 결과로 실제 반영되는 수치 자체의 저장(관계/성장 도메인이 값을 보유), 세계관 설정 데이터 자체(콘텐츠 데이터 도메인)

관련 기존 산출물: 세계관_MVP.md(장소·상황 배경으로 일부 인용), 시나리오_추격자_스크립트.md, 검증_플레이스루.md

---

### 4. 세계관/콘텐츠 데이터 도메인 (World Data)

책임 범위: 게임 전체에서 참조되는 배경 설정(시대상, 장소, 세력, 경지 체계 정의, 인물 프로필)을 보관한다.

포함: 세계관 텍스트 설정, 인물 기본 정보(이름/신분/성격 등 정적 데이터)
포함하지 않음: 특정 사건에서의 동적인 상태 변화(서사/관계/성장 도메인이 각각 관리)

관련 기존 산출물: 세계관_MVP.md, 인물_설매.md의 기본 정보 항목

---

### 5. 진행 상태(세이브) 도메인 (Save/Progress)

책임 범위: 플레이어가 게임을 중단했다가 이어할 수 있도록 현재까지의 성장/관계/서사 진행 상태를 저장하고 불러온다.

포함: 저장/불러오기 시점의 상태 스냅샷 관리
포함하지 않음: 각 수치의 의미나 계산 로직(다른 도메인이 정의)

관련 기존 산출물: 없음 (신규 도메인 — MVP 포함 여부는 5단계에서 판단)

---

## 도메인 경계 원칙

- 각 도메인은 자신이 소유한 데이터만 직접 변경한다. 예: 서사 도메인은 "호감도를 올려야 한다"고 판단만 하고, 실제 수치 변경은 관계 도메인이 수행한다.
- 이 경계는 MVP 단계부터 지키되, 이를 지키기 위한 통신 방식(이벤트, 직접 호출 등)은 이 문서에서 다루지 않는다 — 4단계(도메인 간 상호작용 정의)에서 다룬다.
