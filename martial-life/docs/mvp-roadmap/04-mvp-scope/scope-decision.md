## MVP 포함 여부 판단표

| 도메인 | MVP 포함 | 판단 근거 |
|---|---|---|
| 캐릭터/성장 | 포함 | 경지 상승 없이는 핵심 판타지(성장) 자체가 성립하지 않음 |
| 관계 | 포함 | 호감도 없이는 미연시 정체성이 성립하지 않으며, 성장 도메인의 트리거 자체가 이 도메인에서 발생 |
| 서사/이벤트 | 포함 | 다른 모든 도메인을 실제로 작동시키는 진입점. 이 도메인 없이는 플레이 자체가 불가능 |
| 세계관/콘텐츠 데이터 | 포함 | 서사 도메인이 참조할 최소 데이터가 없으면 대사와 배경을 하드코딩해야 하므로, 분리 자체는 MVP부터 유지 |
| 진행 상태(세이브) | 제외 | 아래 판단 근거 참고 |

## 세이브 도메인 제외 근거

- MVP 검증 목표(제품 정의서의 성공 기준)는 "한 번의 완결된 플레이스루가 무협 미연시로 느껴지는가"이다. 이 목표는 세션 하나를 끝까지 플레이하는 것만으로 검증 가능하며, 중단 후 재개 기능이 없어도 검증에 지장이 없다.
- "이 기능이 없으면 정말 게임이 성립하지 않는가" 기준에 대입하면, 세이브 기능은 없어도 핵심 경험이 유지되는 항목에 해당한다.
- 따라서 세이브 도메인은 MVP 이후, 실제로 여러 사건·인물이 추가되어 플레이 시간이 길어지는 시점에 재도입한다.

## MVP 최종 범위

- 포함 도메인 4개: 캐릭터/성장, 관계, 서사/이벤트, 세계관/콘텐츠 데이터
- 제외 도메인 1개: 진행 상태(세이브)
- 각 포함 도메인의 요구사항 범위는 02-requirements/에 명시된 MVP 범위를 그대로 따른다 (예: 성장 도메인은 평민~삼류만, 관계 도메인은 설매 1명만)

## 재검토 조건

세이브 도메인은 다음 조건 중 하나라도 충족되면 재검토한다.
- 두 번째 인물/사건이 추가되어 한 세션 플레이 시간이 길어질 때
- 실제 플레이테스트에서 "중간에 나갔다 오고 싶다"는 요청이 반복될 때
