# mvp-final-requirements.md

## 목적

5단계에서 확정된 MVP 포함 도메인 4개(캐릭터/성장, 관계, 서사/이벤트, 세계관/콘텐츠 데이터)의 요구사항을 하나의 최종 명세로 통합한다. 제외된 세이브 도메인은 이 문서에 포함하지 않는다.

---

## 캐릭터/성장 도메인 — MVP 최종 요구사항

- 경지 상태값 2단계(평민, 삼류) 조회 및 상승 기능
- 보유 무공 목록에 "일섬" 1개 추가 기능
- 경지 상승은 관계 도메인의 임계점 도달 신호를 받아야만 발생 (자체적으로 조건 판단하지 않음)

## 관계 도메인 — MVP 최종 요구사항

- 설매 1명에 대한 호감도 수치(-3~+5) 관리
- 서사 도메인이 전달하는 증감값 반영
- 호감도 구간별 상태(호감/중립/불신/적대) 판정
- 임계점(+5) 도달 시 서사 도메인에 신호 전달

## 서사/이벤트 도메인 — MVP 최종 요구사항

- 추격자 시나리오 1개 (선택지 A/B/C/D 및 각 후속 분기 전체)
- 사망 엔딩 4종(D, B-사망, C-패배, C-배신 처단) + 성장 성공 엔딩 1종, 총 5개 엔딩 처리
- 선택 결과에 따라 관계 도메인에 증감 요청 전달
- 임계점 도달 신호 수신 시 성장 도메인에 상승 요청 전달
- 세계관/콘텐츠 데이터 도메인으로부터 배경·인물 정보 조회

## 세계관/콘텐츠 데이터 도메인 — MVP 최종 요구사항

- 취선루 배경 설정(시대상, 장소, 세력 미등장 여부) 제공
- 설매 프로필(기본 정보, 성격, 태도 매트릭스) 제공
- 정적 데이터 조회만 지원 (갱신 기능 없음)

---

## MVP 전체 완료 조건

다음 4가지가 모두 만족되어야 이 MVP가 완성된 것으로 본다.

1. 플레이어가 추격자 시나리오를 처음부터 끝까지 최소 1개 경로로 완주할 수 있다
2. 선택에 따라 호감도가 실제로 변하고, 그 결과가 화면(대사)에 반영된다
3. 임계점 도달 시 경지가 실제로 상승하고 무공이 획득된다
4. 5개 엔딩(성공 1 + 사망 4) 중 어느 것에 도달하든 게임이 자연스럽게 종료된다

## 알려진 미확정 사항 (MVP 완성 이후 확정 필요)

- B-사망, C-패배, C-배신 처단의 정확한 발동 조건(확률/숨겨진 수치 등)
- 세이브 도메인 재도입 시점

---

**완료 체크:** 4개 도메인의 MVP 요구사항이 하나의 문서로 통합되었으며, "무엇이 되면 MVP가 완성된 것인가"에 대한 완료 조건이 명확히 정의됨. 이로써 1~6단계 전체 로드맵(제품 정의 → 도메인 도출 → 요구사항 명세 → 상호작용 정의 → MVP 범위 → 최종 요구사항)이 완료됨.
