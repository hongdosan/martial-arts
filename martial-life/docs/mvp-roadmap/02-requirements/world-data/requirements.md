# requirements.md — 세계관/콘텐츠 데이터 도메인 (World Data)

## 기능 요구사항
- 세계관 설정값(시대상, 장소, 세력 범위, 경지 체계 정의)을 서사 도메인이 참조할 수 있어야 한다
- 인물 기본 정보(이름, 신분, 성격, 태도 매트릭스)를 서사 도메인이 참조할 수 있어야 한다

## 데이터 요구사항
- 세계관 텍스트 설정 (MVP 범위: 취선루 배경, 평민~삼류 경지 정의)
- 인물 프로필 데이터 (MVP 범위: 설매 1명)

## 제약 조건
- 이 도메인은 정적 데이터만 다루며, 게임 진행에 따라 변하는 값(호감도, 경지 등)은 갖지 않는다
