# requirements.md — 관계 도메인 (Relationship)

## 기능 요구사항
- 특정 NPC에 대한 호감도 수치를 조회할 수 있어야 한다
- 서사 도메인으로부터 전달받은 증감값만큼 호감도를 갱신할 수 있어야 한다
- 호감도 수치 구간에 따라 관계 상태(호감/중립/불신/적대)를 판정할 수 있어야 한다
- 호감도가 임계점에 도달했음을 다른 도메인에 알릴 수 있어야 한다

## 데이터 요구사항
- NPC별 호감도 수치 (MVP 범위: 설매 1명)
- 호감도 범위(-3~+5)와 구간별 상태 매핑표

## 제약 조건
- MVP에서는 단일 축(호감도)만 사용하며, 신뢰/애정 등 다축 관계는 포함하지 않는다
