# requirements.md — 서사/이벤트 도메인 (Narrative)

## 기능 요구사항
- 플레이어에게 상황(지문)과 선택지를 제시할 수 있어야 한다
- 플레이어의 선택에 따라 다음 분기로 진행할 수 있어야 한다
- 선택 결과로 다른 도메인(관계/성장)에 변경을 요청할 수 있어야 한다
- 특정 분기에서 게임을 종료(엔딩 처리)할 수 있어야 한다

## 데이터 요구사항
- 대화/지문 텍스트, 선택지 목록, 선택지별 분기 대상, 선택지별 관계 도메인 요청값
- 엔딩 유형 (MVP 범위: 성장 성공 1종, 사망 4종 — D/B-사망/C-패배/C-배신 처단)

## 제약 조건
- MVP에서는 사건 1개(추격자 시나리오), 인물 1명(설매)만 포함한다
- 확률/조건부 발동 분기(B-사망 등)의 정확한 트리거 로직은 MVP 요구사항에서 "미정, 추후 확정"으로 명시하고 남겨둔다
