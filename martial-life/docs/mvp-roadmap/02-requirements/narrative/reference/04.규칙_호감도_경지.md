# 규칙_호감도_경지.md

## 호감도 수치 범위

- 최소값: -3
- 최대값: +5 (임계점과 동일하게 설정 — 도달 시 즉시 이벤트 트리거)
- 초기값: 0

## 선택지별 증감 매핑표

| 단계 | 선택지 | 대사 요약 | 호감도 증감 |
|---|---|---|---|
| 1차 분기 | A | "그런 사람 못 봤습니다" | +2 |
| 1차 분기 | B | "손님 신상은 알려드릴 수 없습니다" | +1 |
| 1차 분기 | C | "저... 저쪽 방에..." | -2 |
| A 경로 후속 | A-1 | "곤란해 보이셔서요" | +1 |
| A 경로 후속 | A-2 | "그냥... 눈에 밟혀서요" | +1 |
| A 경로 후속 | A-3 | "저놈들 인상이 더 마음에 안 들어서요" | +2 |
| B 경로 후속 | B-1 | "괜히 얽히기 싫었을 뿐입니다" | 0 |
| B 경로 후속 | B-2 | "제 나름대로는 도와드린 겁니다" | +1 |
| C 경로 후속 | C-1 | "죄, 죄송합니다..." | 0 |
| C 경로 후속 | C-2 | (상처 치료 도구를 가져다줌) | +1 |

## 임계점과 트리거

- 임계점: +5
- 도달 가능 경로: A → A-3 → (A-1 또는 A-2 등 추가 대화로 보정)
- 임계점 도달 시: 결과 이벤트("일섬" 전수 장면) 자동 발생

## 예외 처리 — 선택지 D (즉시 사망 엔딩)

1차 분기의 선택지 D는 호감도 시스템을 거치지 않는다. 선택 즉시 주인공이 사망하며, 호감도 수치나 경지 상태와 무관하게 게임이 그 자리에서 종료된다. 이 분기는 "평민이 무모하게 강자에게 맞서면 죽는다"는 세계관의 냉혹한 법칙을 보여주는 별도 엔딩으로, 4단계 규칙표의 어떤 값도 참조하지 않는다.

## 예외 처리 — B/C 경로의 위험 분기 (신중해도 죽을 수 있음)

B, C 경로에는 각각 대체 사망 결과(B-사망, C-패배, C-배신 처단)가 존재한다. 이 분기들은 호감도 누적과 무관하게 발생할 수 있으며, 정확한 발동 조건(확률, 숨겨진 긴장도 수치 등)은 이번 기획 단계에서 확정하지 않는다. 이는 "신중한 선택도 안전을 보장하지 않는다"는 세계관 원칙을 반영하기 위함이며, 구체적 트리거 메커니즘은 추후 개발 단계에서 결정한다.

## 경지 상승 조건

| 조건 | 결과 |
|---|---|
| 결과 이벤트 발생 (호감도 +5 도달) | 경지: 평민 → 삼류 |

별도의 수련 시간이나 추가 조건 없이, 결과 이벤트 발생 = 즉시 경지 상승으로 단순화한다. (MVP 원칙상 성장 조건을 다중화하지 않음)

## 경로별 최종 도달 가능 호감도 (검증용 참고)

| 경로 | 최종 호감도 | 임계점 도달 여부 |
|---|---|---|
| A → A-3 → (A-1 or A-2) | +5 | 도달 |
| A → A-1 → A-2 | +4 | 미도달 (5단계에서 확인 필요) |
| B → B-2 | +2 | 미도달 |
| C → C-2 | -1 | 미도달 |

---

**완료 체크:** 3단계 스크립트에 등장한 모든 수치(선택지 10개)가 이 문서에 빠짐없이 매핑되어 있으며, 임계점과 경지 상승 조건이 명확히 1개 조건으로 단순화됨.
