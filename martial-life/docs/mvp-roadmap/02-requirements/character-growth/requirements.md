# requirements.md — 캐릭터/성장 도메인 (Character Growth)

## 기능 요구사항
- 주인공의 현재 경지를 조회할 수 있어야 한다
- 특정 조건(다른 도메인으로부터의 트리거 신호) 충족 시 경지를 상승시킬 수 있어야 한다
- 주인공이 보유한 무공 목록에 새 무공을 추가할 수 있어야 한다

## 데이터 요구사항
- 경지 상태값 (MVP 범위: 평민, 삼류)
- 보유 무공 목록 (MVP 범위: 없음 → "일섬" 1개)

## 제약 조건
- 경지는 한 번에 한 단계씩만 상승한다 (단계 건너뛰기 없음)
- MVP에서는 경지 하락(역행) 요구사항을 포함하지 않는다
